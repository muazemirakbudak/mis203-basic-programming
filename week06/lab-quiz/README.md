# Python Club Management System 🎓

This project is a simple console application developed for beginners to learn and practice fundamental Python data structures (`list`, `tuple`) and essential list methods (`append`, `insert`, `remove`, `pop`, `sorted`, `sort`, `len`, `strip`).

## 🚀 Key Steps Implemented in the Project

* **Step 1:** A **tuple** (`branslar`) was defined to store the club's 3 immutable main branches, along with an empty **list** (`tum_ogrenciler`) for students.
* **Step 2:** When entering student names, the `.strip()` method was used to remove any accidental whitespace, and data was stored in a **nested list** format: `[Name, [Branches]]`.
* **Step 3:** The `insert()` method was used to add a "President" to the beginning of the list, and the `len()` function was used to display the total number of students.
* **Step 4:** A specific student was removed from the list using the `remove()` method, while the `pop()` method was used to extract and display the last student removed from the list.
* **Step 5:** A **temporary** sorted copy of the list was created using `sorted()` without altering the original order; subsequently, the `sort()` method was used to **permanently** arrange the main list in alphabetical order.
